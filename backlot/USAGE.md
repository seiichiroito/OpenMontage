# AI動画ハブ(Backlot)の使い方

AI に頼んで作った動画を並べて見る画面です。見るだけで、ここからは作りません。

## 1 本目を作る

1. Mac で OpenMontage のフォルダを開きます。
2. Claude Code か Codex に「〜の動画を作って」と頼みます。
3. 制作が始まると、トップの「できた動画」に自動で並びます。

頼み方の例文は、トップにあります。「写す」を押して、AI に貼ります。
動画があるときは、「次の 1 本を作る」を開くと出ます。

## 確認待ちのとき

台本・場面割り・素材などの区切りで、AI が止まって人の確認を待ちます。トップの札は「確認待ち: 台本」のように出ます。

- 返事は、頼んだ Claude Code か Codex の会話に書きます。この画面からは返事できません。
- 進めてよいとき: 「OK、進めて」
- 直してほしいとき: 「2 場面目を短くして」のように、直す所を書きます。
- やめるとき: 「この動画はやめて」
- 確認は区切りごとに 1 回ずつです。前の「OK」は、次の確認待ちには効きません。

## 出来上がりの場所

- 動画ごとに、OpenMontage のフォルダの `projects/<動画の id>/` に入ります。
- 書き出した動画(mp4)は `projects/<動画の id>/renders/` です。`projects/<動画の id>/` の直下に置かれることもあります。
- 制作の板(カードを押して開く画面)の「Renders」で再生できます。
- `projects/` は Git に入りません。

## 要るキー

- キーが無くても作れます。語り(Piper)・公開の映像素材・絵を動かす編集は、キーなしで動きます。
- キーは OpenMontage のフォルダの `.env` に書きます。無ければ `.env.example` を写して `.env` を作ります。`.env` は Git に入りません。
- 主なキー:

| キー | 使い道 |
|---|---|
| `FAL_KEY` | 画像と動画の生成(FLUX・Veo・Kling など) |
| `GOOGLE_API_KEY` | 画像の生成・語り・動画 |
| `ELEVENLABS_API_KEY` | 語り・音楽・効果音 |
| `OPENAI_API_KEY` | 語りと画像の生成 |
| `PEXELS_API_KEY`・`PIXABAY_API_KEY`・`UNSPLASH_ACCESS_KEY` | 無料の映像・写真の素材 |

- ほかのキーと取り方は `.env.example` に書いてあります。

## トップの見方

- 上の札
  - **待機**: いま動いている制作はありません。
  - **制作中**: 動いている動画の題と段階です(例: 編集 6/8)。
  - **n 本**: 並んでいる動画の数です。
- **できた動画**: いちばん新しい 1 本が大きく出ます。
  - 札の色: 緑は完成、琥珀色は作りかけです。
  - 「完成」「作りかけ」でしぼれます。「新しい順」「長さ順」で並べ替えます。
- カードを押すと、その動画の制作の板(台本・場面・素材・書き出し)が開きます。
- 右上の ☀ / ☾ で、明るい表示と暗い表示を切り替えます。
- 右上の「使い方」で、この文書が開きます。

## 段階の名前

| 画面 | 中身 |
|---|---|
| 調査・企画 | 調べて、案を決める |
| 台本 | 語りと字幕の文 |
| 場面割り | 場面ごとの絵と長さ |
| 素材 | 絵・映像・音を作る |
| 編集・書き出し | つないで動画にする |
| 確認待ち | 人の確認を待っている |

## 開き方

- `python -m backlot open` でトップが開きます。番号(ポート)は `BACKLOT_PORT` です。
- 本人の Mac では常駐しています(127.0.0.1:5250)。
