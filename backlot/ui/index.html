AI動画ハブ

AI に頼んで作った動画が並ぶ所

待機
制作は Mac のフォルダで、AI に頼んで行います。この画面は見るだけです。

使い方

  • 作る Mac の OpenMontage のフォルダで、Claude Code か Codex に「〜の動画を作って」と頼みます。
  • 見る 制作が始まると、ここに自動で並びます。開き直す必要はありません。
  • 開く カードを押すと、その動画の制作の板(台本・場面・素材・書き出し)が開きます。
  • 待機 / 制作中 上の札で、いま AI が動いているかが分かります。
  • この画面からは作りません 押せるのは「開く」と「写す」だけです。
